# 🍏 Ứng dụng Quản lý Thực phẩm Thông minh

Dự án ứng dụng trí tuệ nhân tạo (Computer Vision & DL) để nhận diện thực phẩm, đánh giá độ tươi và quản lý hạn sử dụng.

## 🏗 Cấu trúc dự án
- `/frontend`: Ứng dụng di động xây dựng bằng React Native (Expo).
- `/backend`: Máy chủ API (Python/FastAPI) xử lý logic và tích hợp AI.
- `/models` (nếu có): Nơi chứa các file weights và pipeline huấn luyện YOLO/CNN.

## 🚀 Hướng dẫn khởi chạy
1. Khởi động Backend (xem README trong thư mục `/backend`).
2. Khởi động Frontend (xem README trong thư mục `/frontend`).
